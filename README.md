# 水电站机组运行检修管理平台

面向电站台账、机组运行、调速励磁、主变与闸门、大坝渗流位移监测、机组检修与发电计划的一体化水电站运行检修管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `hydropower-plant-om:entries` 这一项，或调用 `resetModule(模块)`。

## 导轴承：一处判级，三处共用

导轴承原先把上导/下导温度判定抄了三遍（页面、动作、另存导出），两边升级界值还相差 5℃，
大负荷时同一台机组会得出“温度偏高 / 待检修”两种结论。现已收拢到
`frontend/src/domain/bearing/`，页面、动作、导出、重算全部调用同一份实现：

- `rules.ts` —— **唯一判级实现** `evaluateBearing()`：上导温度、下导温度、油位高度、振动数值
  在同一环节处理，输出正常 / 温度偏高 / 待检修三档结论与升级理由；阈值以“规则版本”管理。
- `service.ts` —— 提交检测、确认检修、班组待办投影、汇总、发布新版界值并重算。
- `store.ts` —— 独立持久化键 `hydropower-plant-om:bearing:v2`，含老台账一次性迁移与写入互斥。
- `views/bearing/index.vue` 台账入口；`views/bearing-todos/index.vue` 检修班组待办入口（导航“检修待办”）。

统一界值（规则版本 v2，2026-10-05 起）：

| 通道 | 温度偏高 | 待检修 | 说明 |
| --- | --- | --- | --- |
| 上导温度 | ≥65℃ | ≥70℃ | 现场长期告警值 |
| 下导温度 | ≥60℃ | ≥65℃ | 两侧冲突时取偏严口径，消除相差的 5℃ |
| 油位高度 | ≤200mm | ≤150mm | 越低越差 |
| 振动数值 | >0.10mm | >0.18mm | 导轴承处摆度 |

关键取舍与依据：

- **两边界值冲突按下导侧 60/65 从严算**：下导轴瓦更靠近转轮、承载与润滑更恶劣，漏报烧瓦的
  代价远大于一次提前检修；同时彻底消掉两侧 5℃ 的差。旧页侧口径保留为规则版本 v1，仅用于
  回放迁移前的历史结论（v1 只看温度，升级界值上导 70/75、下导 65/70）。
- **早年只记上导温度的，下导按「上导 − 5℃」推算补齐**：本厂历史台账上下导温差稳定在 4～6℃，
  取中值 5；推算值全程标注“推算（上导−5℃）”，不视为实测；无上导则缺测，绝不臆造；
  油位、振动缺测同样不参与判级。
- **判待检修自动进入检修班组待办**；待办清单从台账实时投影，不另存数据，
  因此待办条数与台账“待检修台数”天然一致；确认检修后状态标记与台数同步回落。
- **同一轴承同一班次重复提交只按第一次算**（白班 08:00–20:00、夜班 20:00–次日08:00，
  夜班跨零点归属开工日），后到的按重复退回并在履历留痕；同一时刻并发写入用业务键互斥只留第一笔。
- **界值调整只允许追加新版本**：发布后对已处理轴承按新版重算当前等级，历史结论保留当时等级并
  在履历上注明“后按 vN 重算为某档”；已检修记录不被重算回退。
- **存量迁移**：从旧通用台账按检测日期（业务时间）回填，保持原编号与既有结论，不被新版重排。
